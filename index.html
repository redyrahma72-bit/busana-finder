Tentang Aplikasi

Aplikasi Pencarian Toko Busana Terdekat merupakan sistem berbasis web yang membantu pengguna menemukan toko busana di sekitar lokasi mereka.

Sistem memanfaatkan fitur GPS (Geolocation) untuk memperoleh lokasi pengguna dan metode K-Nearest Neighbor (KNN) untuk menghitung jarak setiap toko berdasarkan koordinat geografis.

Pengguna dapat mencari toko, melihat alamat, nomor telepon, jarak, serta langsung membuka rute menuju toko melalui Google Maps.

Aplikasi ini masih dalam pengembangan jadi belum sempurna masih banyak kekurangan dari fiturnya jadi untuk para pengguna saya ucapkan minta maaf.
